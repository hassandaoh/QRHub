# QRHub

QRHub turns web links into downloadable QR codes directly in the browser.

## Features

- URL validation and automatic `https://` completion
- High-resolution PNG download
- Scalable SVG download
- Copy original link
- No account, uploads, database, or tracking

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

Designed for Vercel and registered as an External App in Khai-Hub.
